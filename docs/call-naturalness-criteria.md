# 영상통화 자연스러움 합격선

> 2026-10-23 확정 (대표). 팬이 "자연스럽다"고 느끼는 기준은 팬이 이미 아는 실제 영통팬싸다.
> 그래서 감이 아니라 실제 영통팬싸 295통을 잰 값을 합격선으로 쓴다.
> 아바타·화면·대화 흐름을 바꾸는 PR은 이 표의 숫자를 같은 방법으로 다시 재서 본문에 적는다.

## 2. 재는 방법

| 항목 | 방법 |
|---|---|
| 실제 통화 | 말소리: Whisper 단어 시간으로 말 구간을 잡고 쉼 길이·말하는 시간 비율 계산. 얼굴: MediaPipe FaceLandmarker 눈썹~턱 상자 넓이 ÷ 검은 띠를 뺀 영상 내용 영역 |
| 우리 통화 | Playwright 헤드리스 Chromium. 가짜 마이크(질문 녹음 파일)로 말하고, 연습생 영상·음성을 MediaRecorder로 녹화. ffmpeg `silencedetect`(-35dB)로 연습생 말 구간을, 같은 방법으로 질문 녹음 파일에서 팬 말 구간을 잡아 녹화 시각으로 옮긴다. 말하는 시간 비율과 가장 긴 침묵은 **팬+연습생 합집합** 기준(실제 통화 기준과 같게). 대답 시작은 팬 말 끝 → 연습생 소리 시작. 얼굴은 같은 MediaPipe 모델로 통화 화면 캡처를 잰다 |
| 단계별 지연 | agent 로그의 `LAT` 줄 (`fancall/agent/latency_log.py`): end_of_turn, llm_first_token, tts_first_audio, avatar_playback |

- **실시간 가능 여부 (렌더 서버 `tools/ditto_render_server.py`, Colab T4, PyTorch, 긴 변 720)**: 초당 2.9장, 첫 프레임 18초(워밍업 전), 200ms 청크당 중앙값 440ms. T4에서는 실시간(25장/초)이 아니다. Ditto 논문은 TensorRT로 45장/초를 자가보고하므로 4090급에서 다시 재야 한다.


- **소연 눈 판정 (2026-10-27): 같은 12초에서 Ditto+LatentSync가 가장 자연스럽다.** Ditto 단독은 입이 어색하다고 반려. MuseTalk은 빠르지만 선택받지 못했다.
- LatentSync 속도: T4에서는 fp16 판정 조건(`capability > 7`) 때문에 32비트로 돈다. 강제로 fp16을 켜면 단계당 2.03초 → 1.82초(약 10%)뿐이라 T4 한계. DeepCache·단계 수 줄이기 시험은 Colab 무료 GPU 한도가 소진돼 못 했다(2026-10-27 07:3x).
