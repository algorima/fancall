# 영상통화 자연스러움 합격선

> 2026-10-23 확정 (대표). 팬이 "자연스럽다"고 느끼는 기준은 팬이 이미 아는 실제 영통팬싸다.
> 그래서 감이 아니라 실제 영통팬싸 295통을 잰 값을 합격선으로 쓴다.
> 아바타·화면·대화 흐름을 바꾸는 PR은 이 표의 숫자를 같은 방법으로 다시 재서 본문에 적는다.

## 1. 합격선

| 항목 | 합격선 | 근거 (실제 영통팬싸 295통) |
|---|---|---|
| 대화 방식 | 말로 주고받기 | 팬도 말로 한다 (영상에서 팬 말은 자막으로 달림) |
| 누군가 말하고 있는 시간 | 40% 이상 | 사분위 42% / 53% / 64% |
| 팬 말 끝 → 연습생 말 시작 | 1.4초 이내 | 말 사이 쉼 중앙값 1.38초 |
| 침묵 | 3초 넘기 전에 연습생이 채움 | 말 사이 쉼의 4분의 3이 2.86초 이내 |
| 얼굴 크기 | 화면 내용 영역의 8~17% | 중앙값 11.6% (사분위 8.0% / 11.6% / 16.7%) |
| 통화 시작 → 첫 얼굴 | 3초 이내 | 첫 얼굴 등장 사분위 0 / 0 / 3초 |

- 이 표도 가설이다. 실제 사람 3~5명이 걸어 보고 어디서 멈추는지 관찰해 확인한다.
- 원자료는 레포 밖에 있다 (원본 영상은 분석 후 삭제, 메타·분석 결과만 보관).

## 2. 재는 방법

| 항목 | 방법 |
|---|---|
| 실제 통화 | 말소리: Whisper 단어 시간으로 말 구간을 잡고 쉼 길이·말하는 시간 비율 계산. 얼굴: MediaPipe FaceLandmarker 눈썹~턱 상자 넓이 ÷ 검은 띠를 뺀 영상 내용 영역 |
| 우리 통화 | Playwright 헤드리스 Chromium. 가짜 마이크(질문 녹음 파일)로 말하고, 연습생 영상·음성을 MediaRecorder로 녹화. ffmpeg `silencedetect`(-35dB)로 질문 끝 → 연습생 말 시작, 말하는 시간 비율, 가장 긴 침묵. 얼굴은 같은 MediaPipe 모델로 통화 화면 캡처를 잰다 |
| 단계별 지연 | agent 로그의 `LAT` 줄 (`fancall/agent/latency_log.py`): end_of_turn, llm_first_token, tts_first_audio, avatar_playback |
